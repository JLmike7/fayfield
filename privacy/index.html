Privacy

No accounts. No login following you around.

We’re not using analytics yet.

If you pick calendar sources, this browser remembers, using localStorage. That’s it. It isn’t a profile.

Fayfield doesn’t have a public calendar ID yet, so the default source stays hidden. If you later turn on an outside calendar, this browser will ask that publisher for their events.

Unofficial, resident-run. Not the township, not an HOA, not the government. We’re still building this. It isn’t a public launch.
