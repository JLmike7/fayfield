Privacy

There are no accounts on this site. Nothing here creates a login or a cross-device profile.

We are not using analytics yet.

Calendar source choices are saved in this browser only, using localStorage. Those choices are not an account. Fayfield Community has no public calendar ID yet, so the default source stays hidden.

If you later enable an outside calendar, this browser will contact that publisher to load their events.

Unofficial, resident-run. Not a township, HOA, or government site. Development preview — not a public launch.
